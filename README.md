# maxbo

一个开源、非商业的第三方微博阅读客户端（Android），使用 Kotlin 和 Jetpack Compose 开发。

> **状态：早期测试版，只支持 Android。** 方案与进度见 [docs/PLAN.md](docs/PLAN.md)。

## 功能

- **登录**：在应用内打开微博官方登录页，密码只输入在微博的页面里；登录状态保存在本机，可以退出登录。
- **首页**：关注的人的「最新微博」，下拉刷新、上拉加载更多。
- **微博**：正文里的 @、#话题#、链接和表情；九宫格图片、长图、GIF；转发原文；视频；广告标识（只标出来，不过滤）。
- **详情**：长微博全文、评论（按热度或时间）、楼中楼、转发列表。
- **图片和视频**：图片查看器（缩放、左右翻页、下滑关闭），视频播放（地址过期会自动换新地址）。
- **用户主页**：资料和微博列表；从头像、昵称、@ 都能进入。
- **搜索**：顶部的搜索栏和下面的热搜榜。搜索、点热搜条目或正文里的 #话题#，结果都以微博卡片列出（按时间从新到旧，可以一直往下翻），话题还会显示导语和阅读、讨论数；右上角可以切到微博网页版的搜索结果。
- **互动**：点赞、取消点赞，发评论、回复评论、删除自己的评论，转发（可以同时评论、选择可见范围）。只在你点击时发起，不提供任何批量或自动操作。
- **发微博**：文字加图片，可以选公开、好友圈或仅自己可见；可以删除自己的微博。
- **通知**：评论、@我的微博、@我的评论、赞；有未读时导航栏的通知图标变红，只在打开或回到应用、下拉刷新首页时检查，不在后台轮询。
- **平板和折叠屏**：正文限宽居中；宽窗口下首页卡片的图片和视频放在正文右侧，详情页的正文和评论左右并排。
- **设置**：浅色、深色或跟随系统；字体大小（滑动条，在系统字体大小的基础上调大或调小两档，带预览）；图片质量（省流量、标准、原图）；图片缓存上限和清除缓存；关于与免责声明。

**不做的功能**：去广告、批量下载、会员付费内容，这三项永久不做。私信、多账号暂不支持。

## 安装

### Android

在 [Releases](https://github.com/leonfox28/maxbo/releases) 页面下载 `maxbo-vX.Y.Z.apk`，所有手机都用这一个（需要 Android 7.0 及以上）。鸿蒙 HarmonyOS 5/6 可以通过卓易通安装 APK。每个 Release 都附有 `SHA256SUMS.txt`，可以用来核对下载的文件。

从 v0.12.0 起应用用 Kotlin 重写。可以直接覆盖安装旧版，但装上后要重新登录、重新设置。

### iOS

不再提供。v0.2.0 到 v0.11.0 的 Releases 里附有未签名的 IPA，之后的版本不再提供，已经装上的 iOS 版也不会再更新。

## 从源码构建

需要 JDK 17 和 Android SDK（compileSdk 37）。Gradle 由仓库里的 wrapper 下载。

```sh
./gradlew testDebugUnitTest
./gradlew assembleRelease
```

没有 `key.properties` 时，release 包用调试密钥签名，无法覆盖安装 Releases 页面上的正式包。

## 隐私

- 登录在微博官方网页登录页中完成，应用接触不到你的密码。
- 登录状态只保存在你自己的设备上（Android Keystore），退出登录时清除。
- 项目**没有任何服务器**，没有统计、埋点或崩溃上报，不收集任何数据；应用只和微博的服务器通信。
- 只在你操作时请求微博，不在后台轮询或预取，请求频率有上限。遇到验证码时，由你本人在微博的页面里完成。
